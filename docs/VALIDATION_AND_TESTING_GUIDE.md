## 🧪 РІВЕНЬ 1: Автоматизовані тести коректності алгоритмів (`pytest`)

Репозиторій містить понад **65 тестових модулів**, які покривають кожен математичний та архітектурний блок:
- Тести 5-DoF Pose Graph (`tests/unit/geometry/test_pose_graph_*`): перевірка аналітичного якобіана, моделі хіральності (`sign=-1`), адитивності логарифмічних масштабів, збіжності Левенберга–Марквардта.
- Тести фільтрації руху (`tests/unit/tracking/`): перевірка фільтра Калмана, RTS-згладжувача та детектора викидів Z-score.
- Тести сховища (`tests/unit/database/`): перевірка HDF5 v2, LanceDB ANN-пошуку, просторового тайлового індексу.
- Тести керування VRAM (`tests/unit/models/test_model_manager.py`): перевірка LRU-витіснення та бюджету пам'яті.

### 💻 Команди запуску:
```powershell
# Повний запуск усіх тестів із виведенням звіту
pytest tests/ -v

# Запуск суто математичних тестів графа поз
pytest tests/unit/geometry/ -v

# Запуск із розрахунком покриття коду (Code Coverage)
pytest --cov=src --cov-report=term-missing tests/
```

## ⚡ РІВЕНЬ 2: Профілювання заліза та інференсу (`scripts/benchmark_hardware.py`)

Скрипт `benchmark_hardware.py` проводить 3-рівневий мікробенчмаркінг:
1. **Паспорт середовища:** фіксація CPU, моделі GPU, версій CUDA, драйверів, PyTorch.
2. **Мікробенчмарки обчислень:** швидкість FP32/FP16 matmul на GPU, пропускна здатність PCIe (H2D/D2H), швидкість CLAHE-препроцесингу, оптичного потоку Lucas-Kanade та гомографії MAGSAC++.
3. **Пайплайн на реальних моделях:** точний час інференсу DINOv3 (ViT-L/16), ALIKED, LightGlue та векторного пошуку в мілісекундах.

### 💻 Команди запуску:
```powershell
# Запуск повного профілювання на поточному залізі
python scripts/benchmark_hardware.py

# Тестування конвеєра на реальному відео польоту (60 кадрів)
python scripts/benchmark_hardware.py --video "path/to/flight_video.mp4" --frames 60

# Порівняння результатів двох машин або двох конфігурацій (PyTorch vs TensorRT)
python scripts/benchmark_hardware.py --compare benchmarks/hw_base.json benchmarks/hw_trt.json
```
**Результат:** Згенерований JSON-звіт у папці `benchmarks/` та зведена таблиця FPS для розділу 6 пояснювальної записки.

## 🎯 РІВЕНЬ 3: Валідація точності проти Ground Truth (`scripts/validate_vs_ground_truth.py`)

Це **головний чисельний доказ** метричної точності системи. Тестування проводиться на відео з симулятора або польоту з високоточним RTK-GPS логом (`ground_truth.json`).

Скрипт вимірює:
- Похибку центру кожного кадру в метрах на місцевості (з урахуванням проєкції Меркатора та масштабу).
- Похибку оцінки курсу дрона (азимутальний кут $\Delta\theta$ у градусах).
- Похибку відновлення масштабу ($\Delta\text{scale}$ у %).
- Статистику: медіану, 95-й перцентиль (P95), максимальне відхилення та середньоквадратичну похибку (RMSE).

### 💻 Команди запуску:
```powershell
# Валідація відкаліброваної бази проти істинного треку симулятора
python scripts/validate_vs_ground_truth.py `
    --db "path/to/project/database.h5" `
    --gt "path/to/FlightSimulator/ground_truth.json" `
    --csv "benchmarks/propagation_accuracy.csv"
```
**Результат у консолі:**
```text
  All frames             n= 1240  median=   1.35m  p95=   3.12m  max=   4.20m
  Angle error (deg)      n= 1240  median=   0.82°  p95=   1.95°  max=   2.80°
  Scale error (%)        n= 1240  median=   1.10%  p95=   2.40%  max=   3.50%
```

## 🌍 РІВЕНЬ 4: Міжнародні SOTA-бенчмарки VPR (`scripts/retrieval_metrics.py`)

Скрипт реалізує метрики міжнародного бенчмарку для низьковисотних БПЛА **AnyVisLoc** (представленого на конференції **CVPR 2026 Findings**):
1. **Recall@K (K=1, 5, 10):** частка випадків, коли правильний еталонний кадр опинився серед перших $K$ результатів пошуку (радіус хіта 5 м).
2. **SDM@K (Spatial Distance Metric):** ранг-зважене просторове загасання відстані до істинної позиції.
3. **PDM@K (Proportional Distance Metric):** метрика похибки, нормалізована шириною поля зору (футпринта) камери в метрах ($R_i = d_i / W_i$). Показує реальне відсоткове перекриття кадрів.

### 💻 Як провести дослідження:
```powershell
# Розрахунок метрик VPR для еталонного маршруту
python scripts/retrieval_metrics.py
```

### 🏆 Публічні датасети, на яких можна запустити валідацію:
1. **AnyVisLoc Dataset (2025/2026):** Мультиракурсний низьковисотний датасет знімків із дронів над різними ландшафтами (місто, ліс, передмістя).
2. **ALTO Dataset (Airborne Laser and Topometric Odometry):** Синхронізовані реальні польоти БПЛА з лазерними сканерами та камерами в різні пори року (літо/осінь/зима).
3. **University-1652 / DenseUAV:** Стандартні датасети для задачі cross-view / cross-altitude drone geo-localization.

## 🛡️ РІВЕНЬ 5: Відмовостійкість та стрес-тести (`scripts/soak_test.py`)

Демонструє стабільність програмного комплексу в умовах збоїв та тривалої автономної роботи (12+ годин):
- **Симуляція збоїв (Fault Injection):** штучні розриви RTSP-відеопотоку, пошкоджені чорні кадри, стрибки яскравості, переповнення буферів.
- **Моніторинг витоків пам'яті:** контроль стабільності RAM та VRAM через `psutil` і `torch.cuda.memory_allocated`.

### 💻 Команди запуску:
```powershell
# Запуск 1-годинного стрес-тесту з симуляцією випадкових збоїв
python scripts/soak_test.py --project "path/to/project" --duration 3600 --fault-injection
```

## 📊 Абляційні дослідження (Ablation Studies) для захисту

Для наукової частини дипломної роботи рекомендується провести 4 порівняльні експерименти та включити їхні графіки у презентацію:

### 1. Дослідження глобального дескриптора (DINOv2 vs DINOv3 sat493m vs VLAD)
- **Мета:** Довести перевагу моделі DINOv3, навченої на 493M супутникових знімках, над стандартною DINOv2.
- **Як виконати:** Змінити в `user_config.json` параметр `models.global_descriptor.backend` (`"dinov2"` $\to$ `"dinov3"`) та порівняти Recall@1 за допомогою `scripts/retrieval_metrics.py`.

### 2. Дослідження впливу 5-DoF Pose Graph оптимізації
- **Мета:** Довести, що оптимізація графа поз із замиканням петель усуває нагромадження просторового дрейфу на довгих дистанціях.
- **Як виконати:** Порівняти лінійну пропагацію без графа проти повної 5-DoF оптимізації LM через `scripts/validate_vs_ground_truth.py`.

### 3. Дослідження семантичного маскування YOLOv11-seg
- **Мета:** Довести, що видалення динамічних об'єктів (автомобілів на трасах) підвищує Inlier Ratio та виключає хибні прив'язки.
- **Як виконати:** Використати `scripts/ab_localization.py` на відео з інтенсивним трафіком:
  ```powershell
  python scripts/ab_localization.py logs/app_without_mask.log logs/app_with_yolo_mask.log
  ```

### 4. Дослідження фільтрації руху (Raw GPS vs Kalman vs RTS Smoother)
- **Мета:** Продемонструвати плавність траєкторії та відсутність телепортаційних стрибків завдяки комплексу TrajectoryFilter.

## 📈 Як згенерувати графіки для доповіді та плакатів

Ви можете використати стандартний Python-скрипт з бібліотекою `matplotlib` на основі отриманого файлу `benchmarks/propagation_accuracy.csv`:

```python
import matplotlib.pyplot as plt
import pandas as pd

# Завантаження результатів валідації
df = pd.read_csv("benchmarks/propagation_accuracy.csv")

plt.figure(figsize=(10, 5))
plt.plot(df["slot_id"], df["error_m"], label="Похибка локалізації (м)", color="#2563eb", lw=1.5)
plt.axhline(df["error_m"].median(), color="#16a34a", linestyle="--", label=f'Медіана: {df["error_m"].median():.2f} м')
plt.axhline(df["error_m"].quantile(0.95), color="#dc2626", linestyle=":", label=f'P95: {df["error_m"].quantile(0.95):.2f} м')

plt.title("Похибка топометричної локалізації вздовж маршруту польоту БПЛА", fontsize=12)
plt.xlabel("Номер кадру (Slot ID)", fontsize=10)
plt.ylabel("Абсолютна похибка на місцевості (м)", fontsize=10)
plt.grid(True, alpha=0.3)
plt.legend()
plt.tight_layout()
plt.savefig("benchmarks/localization_error_plot.png", dpi=300)
plt.show()
```

Ці матеріали, цифри та графіки забезпечать **залізобетонну доказову базу**, яка підтвердить, що дипломна робота виконана на рівні передових міжнародних досліджень у галузі автономної робототехніки та комп'ютерного зору.
